天凉了，我们做了道板栗烧鸡🌰
正文 + 标签
杭州这几天风一凉，后厨就开始琢磨秋天的菜。板栗烧鸡是最近刚端上桌的一道，我们自己先试了几锅。 板栗一颗颗都是粉的，跟鸡块一起在锅里焖到软糯，咬开是吸饱了汤汁的那种甜香，不干也不噎。鸡肉是现点现炒的，下锅那一下滋啦作响，端上桌还冒着热气，肉紧实，酱汁浓，挂在饭上正好。 我们家的米饭免费续。所以这道菜的汁千万别浪费，一碗接一碗添起来才过瘾。
